# Farhood-CV — صفحة تعريفية بروح بابل

صفحة هبوط (Landing Page) شخصية فخمة بالعربية (RTL) للمهندس **حسين عباس فرهود**،
بهوية بصرية مستوحاة من **بوابة عشتار وحضارة بابل**: لازوردي، برونزي، وذهبي
مع زخارف مسمارية وصور أيقونية لبابل. بنية ثابتة بالكامل (HTML / CSS / JS)
بدون أي اعتماد على الإنترنت وقت التشغيل.

## المميزات

- صور بابل مولّدة بالذكاء الاصطناعي: بوابة عشتار، حدائق بابل المعلقة، أسد بابل،
  اللوح المسماري، وزقورة أيتمانانكي
- شاشة تحميل على هيئة **بوابتَي عشتار تنفتحان** مع عدّاد عربي
- انتقالات أقسام بـ **ستائر لازوردية** بنقش الطابوق تنسحب سينمائيًا
- أقنعة نصية صاعدة كلمة كلمة مع توهج ذهبي يعبر العناوين
- **معرض أفلي مثبّت (Pinned Horizontal Scroll)** لباقي معالم بابل
- كشف الصور بـ clip-path مع Parallax عميق وتأثير Ken Burns في الهيرو
- غبار ذهبي ولازوردي متحرك على Canvas، مؤشر ماوس مخصص، أزرار مغناطيسية،
  بطاقات بإمالة ثلاثية الأبعاد
- شهادة دورة التحليل المخبري الطبي (36 ساعة — Pulse Training Center) منظّمة ومصحّحة
  من صورة الجوال، مع نافذة عرض مكبّر (Lightbox) داخل قسم الخبرات
- خطوط عربية محلية (Amiri للعناوين الفخمة + Cairo للنصوص) ومكتبة GSAP محلية بالكامل
- متجاوب مع الجوال، قائمة بانتشار دائري، ودعم `prefers-reduced-motion`

## البنية

```
├── index.html          # الصفحة الكاملة
├── assets/             # الصور البابلية (jpg)
├── css/
│   ├── fonts.css       # الخطوط المحلية
│   └── style.css       # التنسيقات والهوية البابلية
├── js/
│   └── main.js         # الحركات والتفاعل والمعرض والغبار
├── fonts/              # ملفات woff2
└── vendor/gsap/        # GSAP + ScrollTrigger محليًا
```

## التشغيل

لا يحتاج بناء — يكفي فتح `index.html` أو تشغيل خادم محلي:

```bash
python3 -m http.server 8000
```
