# Farhood-CV — صفحة تعريفية احترافية

صفحة هبوط (Landing Page) شخصية فخمة بالعربية (RTL) للمهندس **حسين عباس فرهود**،
بنيوية ثابتة بالكامل (HTML / CSS / JS) بدون أي اعتماد على الإنترنت وقت التشغيل.

## المميزات

- تصميم داكن فخم: أسود كحلي مع ذهبي ولمسة خضراء حيوية بطابع الهندسة الوراثية
- مشهد حمض نووي DNA متحرك مرسوم على `Canvas` مع نجوم متلألئة وتفاعل مع الماوس
- انتقالات احترافية بـ **GSAP + ScrollTrigger**: أقنعة نصية، ظهور متدرج، خط زمني يمتلئ مع التمرير
- مؤشر ماوس مخصص، أزرار مغناطيسية، بطاقات بإمالة ثلاثية الأبعاد وبقعة ضوء
- شاشة تحميل بعدّاد، شريط تقدم قراءة، شريط نصوص متحرك، قائمة جوال بانتشار دائري
- خطوط عربية محلية (Changa + Tajawal) — تعمل بدون اتصال
- متجاوب بالكامل مع الجوال والأجهزة اللوحية، ودعم `prefers-reduced-motion`

## البنية

```
├── index.html          # الصفحة الكاملة
├── css/
│   ├── fonts.css       # تعريفات الخطوط المحلية
│   └── style.css       # كل التنسيقات
├── js/
│   └── main.js         # الحركات والتفاعل ومشهد DNA
├── fonts/              # ملفات woff2 المحلية
└── vendor/gsap/        # مكتبة GSAP وScrollTrigger محلياً
```

## التشغيل

لا يحتاج أي بناء — يكفي فتح `index.html` في المتصفح، أو تشغيل خادم محلي:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## تخصيص المحتوى

كل النصوص داخل `index.html` مباشرة، والألوان والمتغيرات في بداية `css/style.css`
داخل `:root`.
