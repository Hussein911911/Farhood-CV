# Farhood-CV — السيرة الذاتية لـ حسين عباس فرهود

سيرة ذاتية تفاعلية فخمة بالعربية (RTL) بهوية بصرية مستوحاة من **بوابة عشتار وحضارة بابل**:
لازوردي، برونزي، وذهبي مع خطوط Amiri وCairo وصور أيقونية لبابل. موقع ثابت بالكامل
(HTML / CSS / JS) يعمل بدون إنترنت وقت التشغيل.

## فلسفة الحركة

- **انبثاق ناعم (Pop Reveals):** كل عنصر ينبثق بهدوء لحظة دخوله الشاشة عبر
  IntersectionObserver — بلا أي حركات مربوطة بالتمرير (لا pin ولا scrub ولا parallax)
- بوابة عشتار افتتاحية ثلاثية الأبعاد تنفتح عند أول زيارة
- غبار ذهبي ولازوردي على Canvas يتوقف تلقائياً خارج الشاشة
- مؤشر ماوس مخصص، أزرار مغناطيسية، بطاقات بإمالة 3D، عدادات وأشرطة لغات تنبض once
- نافذة عرض مكبّر (Lightbox) للشهادة ومعالم بابل، تعمل بالكيبورد (Escape)

## أقسام السيرة

٠١ نبذة تعريفية • ٠٢ المؤهل العلمي • ٠٣ الخبرات والتدريب • ٠٤ الشهادات
• ٠٥ المهارات واللغات • ٠٦ معرض بابل • ٠٧ التواصل

## الشهادة

شهادة دورة التحليل المخبري الطبي (Pulse Training Center — ٣٦ ساعة — أكتوبر ٢٠٢٤)
مصحّحة ومنظّمة من صورة الجوال (قصّ منظوري، توحيد إضاءة، توضيح نص) داخل
`assets/certificate.jpg`، معروضة في قسم مستقل بإطار مزخرف وقابلة للتنزيل والعرض المكبّر.

## البنية

```

├── js/
│   └── main.js         # البوابة، الانبثاق، التفاعل، الغبار
├── fonts/              # ملفات woff2 محلية

```
